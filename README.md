# Personal Portfolio Website

A sleek, modern, and fully responsive personal portfolio website designed to showcase a professional bio, core skill sets, and creative projects. This project includes an interactive theme customization panel that allows users to switch between different color schemes seamlessly in real time.

## 🚀 Features

- **Fully Responsive Design:** Optimized for a seamless user experience across mobile, tablet, and desktop devices.
- **Dynamic Style Switcher:** An interactive sidebar UI widget allowing visitors to toggle custom accent color skins and dark/light themes.
- **Project Gallery:** A beautifully styled grid layout dedicated to showcasing creative portfolios and work examples.
- **Clean Architecture:** Organized code layout utilizing pure HTML, modular vanilla CSS, and custom JavaScript animations.

## 💻 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the directory:**
   ```bash
   cd personal-portfolio-website
   ```
3. **Open the project:**
   Simply double-click the `index.html` file to open it directly in any modern web browser, or serve it using an extension like *Live Server* in VS Code.
